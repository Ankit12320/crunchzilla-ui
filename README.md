# Crunchzilla UI

Storefront for Crunchzilla's traditional Indian staples: Tilkut, Makhana, Sattu, Katarni Chura, Poha and Jaggery. Built with Next.js 16, React 19, TypeScript and Tailwind CSS v4.

```bash
npm install
npm run dev      # http://localhost:3000
```

**New to the project? Read [PROJECT_GUIDE.md](PROJECT_GUIDE.md).** It covers the folder structure, how pages are built, where every piece of content lives, and step-by-step recipes for common changes.
